01

범위

이미지 다건을 한 번에 올려 판정하고 결과를 보고서로 내보내는 흐름까지가 대상. 판정 이력 저장과 인증은 제외하며, 결과는 보고서로만 보존.

In Scope

  • 이미지 다건 일괄 업로드 (png · jpg)
  • Mkr1 주파수 · 전력 OCR 추출
  • 단위 정규화 (GHz/MHz/Hz · µW/mW/dBm)
  • 규정 기준 · 서식 기준 판정 병행 산출
  • 추출 실패 값의 수동 보정 후 재판정
  • 판정 보류 상태 별도 구분
  • 서식 기반 docx 보고서 1건 취합

Out of Scope

  • 그래프 곡선 형상 자체의 분석
  • 시험 장비 직접 연동 · 실시간 측정
  • 판정 이력 저장 및 과거 결과 재조회
  • Mkr1 외 항목(Span · RBW · Atten) 판정
  • 사용자 인증 · 권한 관리
  • 보고서 내 원본 이미지 첨부
  • 보고서 서식 구조 변경
02

추출

판정 대상은 화면 우상단 마커 판독값 2종. 화면 설정값(Center Freq · Span · RBW)은 추출하되 판정에는 쓰지 않음.

Mkr1 2.405095 GHz 641.83 µW Ref 10.00 mW

확인 필요 처리 조건

  • 값 문자열 미검출 — Mkr1 라벨은 읽혔으나 숫자가 없는 경우
  • 형식 불일치 · 단위 누락 — 소수점 앞 자릿수가 잘린 부분 인식값 포함
  • 물리적으로 성립하지 않는 값 — 전력 0 이하는 FAIL이 아닌 보류
  • 인식 신뢰도 0.60 미만 — 형식 검증이 1차 기준, 신뢰도는 보조

Mkr1과 같은 행에 놓인 Ref 10.00 mW가 전력값으로 잘못 읽히므로, 마커 라벨 기준 우측·하단 위치 제약을 함께 적용.

03

판정 기준

두 기준을 동시에 적용하고 결과를 각각 표시. 종합 판정은 양쪽 전 항목이 PASS일 때만 PASS이며, 두 결과가 엇갈린 건은 보고서 특이사항에 기재.

기준 A · 판정 규정

module_1/docs/pass-fail-rules.md

FREQ-012.404000 GHz ≤ f ≤ 2.406000 GHz
POWER-010 < P ≤ 700.00 µW

경계값 2.404000 · 2.406000 GHz · 700.00 µW는 모두 PASS.

기준 B · 보고서 서식

module_1/data/report_template.docx

측정값(dBµV/m) = 10·log10(µW / 1000) + 107 + CF 마진(dB) = Limit − 측정값  →  마진 ≥ 0 : PASS
Limit54 dBµV/m (기본값, 화면에서 수정 가능)
CF0 dB (무보정 기준)

05

보고서

서식의 표 구조와 문구는 바꾸지 않고 플레이스홀더 값만 채워 생성. 업로드 건 전체를 취합해 docx 1건으로 출력.

구역채워지는 값입력 주체
머리말문서번호 · 시험일 · 시험명 · 담당자 · 적용 규격 · 시료명 · CF사용자 입력 (시험일 자동)
판정 요약총 건수 · PASS · FAIL · 종합판정자동 (보류 건 제외 집계)
측정 결과주파수 · 전력 · dBm · dBµV/m · Limit · 마진 · 판정자동 (보류 포함 전 건)
특이사항규정 버전 · 보류 건 목록 · 기준 A·B 상이 건자동
서명작성자 · 검토자사용자 입력
  • 파일명 규칙 judgment-report_YYYYMMDD-HHMMSS.docx, 저장 위치 project/output
  • 적용 규격 기본값 FCC Part 15 Subpart B Class B (3 m)
  • 판정 결과는 서버에 저장하지 않으므로 새로고침 시 소실됨을 화면에서 안내

07

미확정

기준 B의 Limit 기본값 54 dBµV/m

보고서 서식이 FCC Part 15 Subpart B Class B (3 m)를 Limit 출처로 명시하고 있어 그대로 반영. 다만 2.4 GHz 대역은 Part 15.247(ISM) 적용 대상일 가능성이 있어 적용 대역·측정조건 적합성 확인 필요. 화면에서 수정 가능하도록 설계되어 개발 착수에는 지장 없음.

서식의 dBµV/m 환산식과 CF는 서식 자체에 교육용 가정값으로 표기되어 있으며 실측 보정값이 아님.
