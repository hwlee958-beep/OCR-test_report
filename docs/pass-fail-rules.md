# PASS/FAIL 판정 규정

## PASS/FAIL 기준

| 규칙 ID | 항목 | PASS 조건 | FAIL 조건 |
|---|---|---|---|
| FREQ-01 | Mkr1 주파수 | 2.404000 ≤ f ≤ 2.406000 GHz | 하한 미만 또는 상한 초과 |
| POWER-01 | Mkr1 전력 | 0 < P ≤ 700.00 µW | 700.00 µW 초과 |

- 주파수 범위: 2404.000~2406.000 MHz 또는 2,404,000,000~2,406,000,000 Hz와 동일
- 전력 상한: 700.00 µW = 0.70000 mW
- 모든 경계값 포함: 2.404000 GHz·2.406000 GHz·700.00 µW는 해당 항목 PASS
- 전력 0 이하: 이번 자료의 로그 전력 표시와 맞지 않는 입력으로 판정 보류, FAIL로 처리 금지
- 이 범위 선택 목적: 주파수 이탈·전력 초과·경계값·단위 변환 사례를 함께 학습
- 규정 변경 시 버전 증가 및 전체 이미지 재판정, 기존 결과의 규정 버전 보존
